Naming standards

        
Every request becomes one short-lived branch and one pull request.

        

          
Branch
portal/<image|vm>/<name>-<YYYYMMDD>-i<issue>

          
Commit / PR
feat(image): add image <name>

          
chore(image): update image <name>

          
feat(vm): create vm <name> on <cloud>

          
chore(vm): decommission vm <name>

          
Trailers
Requested-by, Request-source, Request-ref

          
Merge
squash, 1 approval, branch auto-deleted
